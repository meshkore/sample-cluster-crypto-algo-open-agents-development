# Public mirror

Source for the read-only Cloudflare presentation layer. It never runs research,
trading, agents or arbitrary cluster input; it stores only the most recent,
bounded snapshot sent by the local QuantLab publisher.

See [[docs/deploy/public-state-mirror]].
