# Initiative-anchored execution

Every material agent turn must locate or create one initiative and one task
before changing code or external state. Task `category` must equal its module.
Use `#<id>` in load-bearing chat updates. Follow the canonical decision chain in
<https://meshkore.com/standard#24-initiative-anchored-execution-v23>.
