# Standard evolution

Compare `.meshkore/STANDARD_VERSION` with
<https://meshkore.com/standard/version>. If the published integer is higher,
read the intervening changelog at
<https://meshkore.com/standard/CHANGELOG.md>, apply its migrations, validate,
and update the local marker in the same reviewed commit.
